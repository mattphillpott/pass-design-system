# Pass Functional Skills — Landing Page

## Files
- `PFS Landing Page.html` — entry point. Open in a browser.
- `PFS Sections.jsx` — all page sections (hero, form, routes, process, careers, reviews, why, footer, sticky bar).
- `PFS Icon.jsx` — icon loader component.
- `colors_and_type.css` — design tokens, typography, buttons, inputs, cards (loads Inter from Google Fonts).
- `assets/icons/*.svg` — local Lucide-style icons.
- `assets/logos/pass-wordmark.svg` — Pass logo.

## Run
Just open `PFS Landing Page.html` in a modern browser, or serve the folder with any static file server (e.g. `npx serve`). React + Babel are loaded from unpkg via CDN — an internet connection is required for first load.

## Notes
- The form is a demo; the submit handler shows an alert.
- The trust-strip company "logos" are illustrative placeholders (text marks), not real brand logos.
